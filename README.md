# ATRI-LK项目的插件库

在这提交新插件与插件错误。

## 如何添加新插件

### 1. 直接提交

1. 请将新插件放入`plugins`目录下，rss子插件请放入`plugins/rss`下(暂不支持其他子插件)
2. 请在`plugin.json`的末尾添加以下插件信息:

```text
"插件名": {
    "path": "plugins.your_plugin",
    "docs": "插件介绍",
    "version": "版本号",
    "author": "作者",
    "is_dir": true
    //可选
    "res": ["res/your_res.res", "res/your_res"],
    //可选：插件种类与版本声明，详见下文
    "type": "娱乐服务",
    "framework": "0.24",
    "lkapi": 2
}
```

> 资源位置目前只支持项目内的单文件与文件夹，外部资源请在插件中下载

> 需要安装新依赖需要将依赖写在你的插件目录的`requirements.txt`

### 插件种类与版本声明（可选）

商店会读取三个可选字段，用来提示用户插件与当前框架是否匹配：

| 字段 | 含义 | 取值 |
|---|---|---|
| `type` | 插件种类 | `系统服务` `LK扩展服务` `功能性服务` `娱乐服务` `游戏服务` `订阅服务` `其他服务` `隐藏服务`，与插件内 `Service.ServiceType` 一致 |
| `framework` | 插件开发所依据的框架版本 | **单一版本号**，如 `0.24` |
| `lkapi` | 插件所依赖的 lkapi 接口版本 | 整数，如 `2`，对应 `ATRI.system.lkapi.API_VERSION` |

- `framework` **只能写一个版本号**，不要写 `>=0.24`、`^0.24`、`0.23 <0.25` 这类约束
- 插件能否使用，取决于该版本号是否落在当前框架的兼容区间内；区间集中定义在
  `ATRI/version.py` 的 `COMPAT_FRAMEWORK`，当前为 `0.24`-`0.25`
- 不写 `framework` 会显示「未知兼容性」；低于区间下界显示「版本过时，可能不兼容」
- `lkapi` 请填**最新的接口版本**；lkapi 存在变动说明，声明后商店会提示使用者确认适配
- 三项都可省略，省略即不做兼容性标注
- **只标注、不拦截**：不匹配时商店会提示原因，但仍然允许安装

仓库型插件（`repo` 形式）请把同样的字段写在自己的 `meta.yml` 里，
商店安装/更新时会读取该文件；`plugin.json` 里也写一份可作为兜底。
